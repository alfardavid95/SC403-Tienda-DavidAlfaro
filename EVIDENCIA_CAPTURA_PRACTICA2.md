# Evidencia de captura - Práctica #2

## Objetivo

Este documento describe cómo debe tomarse la captura de pantalla solicitada para la entrega de la Práctica #2.

## Ruta que debe mostrarse

La captura debe tomarse desde la siguiente ruta:

http://localhost:8080/consultas/listado

## Elementos que debe mostrar la captura

La imagen debe evidenciar que la consulta ampliada está funcionando correctamente.

La captura debe mostrar:

- La URL en el navegador.
- El formulario de la Práctica #2.
- Los filtros ingresados.
- La tabla de productos resultante.
- Al menos un resultado visible de la consulta.

## Valores recomendados

Para generar una captura clara se pueden utilizar estos valores:

- Categoría: Todas las categorías
- Texto en descripción: Monitor
- Precio inferior: 10000
- Precio superior: 80000
- Existencia mínima: 1

## Formato requerido

La captura debe guardarse en formato JPG.

## Recomendación para la entrega

Antes de tomar la captura se debe verificar que:

1. El proyecto esté ejecutándose correctamente.
2. MySQL esté activo.
3. La base de datos techshop tenga datos cargados.
4. La consulta muestre resultados visibles.
5. La pantalla no muestre errores de consola o navegador.
